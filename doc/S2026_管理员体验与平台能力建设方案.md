# S2026 管理员体验与平台能力建设方案

## 1. 背景

当前系统已经具备项目管理、申报配置、基本信息字段选用、申报材料填报、审核流等基础能力。随着申报配置逐步复杂化，管理员角色在实际使用中会遇到以下问题：

- 项目申报配置重复劳动多，复杂打印表格需要反复手工调整。
- 配置项越来越多，缺少模板化、复用、版本对比和影响分析能力。
- 打印申报表对版式要求高，需要更强的所见即所得和校验能力。
- 申报过程涉及多角色、多单位、多状态，需要更完善的权限、流程、统计和归档能力。

本方案面向管理员角色，设计一组可分阶段落地的平台能力，提升配置效率、数据质量、审计追踪和申报管理效率。

## 2. 目标

- 降低管理员创建项目和申报配置的成本。
- 提升申报表打印布局配置的准确性和可复用性。
- 建立配置版本、模板、校验、影响分析机制。
- 完善权限、流程、导出、统计、归档等后台管理能力。
- 让管理员能够稳定管理多个年度、多个项目、多个单位的申报工作。

## 3. 角色与使用场景

### 3.1 系统管理员

负责系统基础配置、角色权限、主数据维护、全局模板维护。

典型场景：

- 配置角色权限。
- 维护基本信息字段主数据。
- 维护申报配置模板库。
- 查看全局操作日志。

### 3.2 项目管理员

负责创建项目、配置申报表、管理申报材料、组织审核和导出归档。

典型场景：

- 从历史项目复制申报配置。
- 调整申报表打印布局。
- 监控各单位申报进度。
- 批量导出申报表和附件。

### 3.3 单位管理员

负责本单位申报人材料初审、退回修改、汇总报送。

典型场景：

- 查看本单位申报列表。
- 审核申报材料。
- 批量导出本单位材料。

## 4. 总体功能架构

建议按以下模块建设：

- 配置复用中心：模板库、历史项目复制、配置导入导出。
- 配置版本中心：版本对比、发布记录、回滚、影响分析。
- 打印布局中心：所见即所得、分页预览、布局校验、PDF 预览。
- 主数据中心：基本信息字段、字典、校验规则、字段影响范围。
- 权限与流程中心：角色权限、项目级权限、审批流配置。
- 数据管理中心：申报列表、批量导出、统计分析、归档。
- 审计与安全中心：操作日志、敏感导出记录、水印、只读归档。

## 5. 功能设计

### 5.1 配置模板库

#### 功能说明

将常用申报配置沉淀为模板，管理员创建项目时可以直接选择模板初始化。

#### 核心能力

- 新建模板。
- 从当前项目保存为模板。
- 从模板创建项目配置。
- 模板分类：人才类、奖项类、项目类、年度申报类。
- 模板版本管理。
- 模板预览。

#### 数据设计

新增 `declaration_config_templates`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| name | varchar | 模板名称 |
| category | varchar | 模板分类 |
| description | text | 说明 |
| config_json | json | 申报配置 |
| version | int | 模板版本 |
| status | varchar | enabled / disabled |
| created_by | bigint | 创建人 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

#### 前端入口

- 项目管理 > 申报配置 > 从模板创建。
- 申报配置编辑页 > 保存为模板。
- 系统管理 > 申报配置模板。

### 5.2 历史项目复制

#### 功能说明

新建项目时可选择历史项目作为来源，一键复制申报配置、基本信息字段选用、打印布局、审批流等配置。

#### 复制范围

- 项目申报配置版本。
- 基本信息字段选用。
- 模块、子模块、内容块。
- 打印表格布局。
- 审批流配置。

#### 注意事项

- 复制后生成新的配置版本。
- 内部 key 重新生成，避免跨项目冲突。
- 复制后状态默认为草稿。

### 5.3 配置导入导出

#### 功能说明

管理员可导出当前项目申报配置 JSON，并在其他项目导入。

#### 能力要求

- 导出 JSON。
- 导入前预校验。
- 导入差异预览。
- 导入后生成新版本。
- 支持覆盖当前草稿或另存为新版本。

#### 校验项

- JSON 格式合法。
- 必需字段存在。
- 模块 key 不重复。
- 字段 key 不重复。
- 打印总列数与占格关系合法。
- 引用的基本信息字段存在。

### 5.4 配置版本对比

#### 功能说明

管理员发布配置前，可以对比两个版本的差异。

#### 对比维度

- 基本信息字段变化。
- 模块新增、删除、改名。
- 内容块变化。
- 字段变化。
- 打印布局变化。
- 审批流程变化。

#### 展示方式

- 左右对比。
- 结构树差异标记。
- JSON Diff 作为高级视图。
- 高风险变更提示。

#### 高风险变更

- 删除已被申报材料使用的字段。
- 修改字段 key。
- 修改字段类型。
- 删除内容块。
- 修改已发布项目的审批流。

### 5.5 配置影响分析

#### 功能说明

管理员修改字段或配置时，系统提示该变更影响哪些项目、材料和导出模板。

#### 示例

删除字段前提示：

```text
该字段已被 3 个项目使用，涉及 128 份申报材料。
删除后历史材料仍保留原始数据，但新填报页面不再展示该字段。
```

#### 实现方式

- 维护配置引用关系。
- 发布前扫描当前配置。
- 字段主数据页面展示引用项目数。

### 5.6 打印布局中心

#### 功能说明

强化申报配置中的打印表格布局能力，保证管理员看到的配置效果接近最终导出效果。

#### 已有能力

- 基本信息字段打印表格布局。
- 列表块打印表格布局。
- 表单汇总大文本布局。
- 声明签章布局。

#### 后续增强

- A4 分页预览。
- 页眉页脚配置。
- 页码配置。
- 分页线提示。
- 行高配置。
- 单元格边框样式。
- 单元格文字对齐方式。
- 打印水印。
- PDF 预览。

#### 布局校验

发布前执行：

- 是否存在空标题列。
- 总列数是否合理。
- 占格是否超出总列数。
- 左侧合并标题是否导致内容列过窄。
- 内容块是否为空。
- 签章栏占格总和是否匹配。

### 5.7 主数据管理

#### 功能说明

集中维护基本信息字段、字典、校验规则，项目配置只负责选择和布局。

#### 字段能力

- 字段编码。
- 默认标签。
- 字段类型。
- 所属模块。
- 默认是否必填。
- 字典类型。
- 排序。
- 启用/停用。
- 校验规则。

#### 管理要求

- 字段被项目引用时，不允许直接删除。
- 字段停用后，历史项目仍可读取旧配置。
- 字段改名不影响字段 key。
- 字段类型变更需要提示影响范围。

### 5.8 权限管理

#### 功能说明

按角色和项目范围控制管理员能力。

#### 权限点示例

| 权限点 | 说明 |
| --- | --- |
| project:create | 创建项目 |
| declaration_config:view | 查看申报配置 |
| declaration_config:edit | 编辑申报配置 |
| declaration_config:publish | 发布申报配置 |
| declaration_config:template_manage | 管理配置模板 |
| material:review | 审核申报材料 |
| material:export | 导出材料 |
| audit_log:view | 查看操作日志 |

#### 项目级授权

同一用户可在不同项目拥有不同权限。例如：

- A 项目：项目管理员。
- B 项目：只读查看。

### 5.9 审批流配置

#### 功能说明

支持不同项目配置不同审批流程。

#### 流程能力

- 节点配置。
- 节点处理角色。
- 节点可退回目标。
- 节点是否允许补充材料。
- 节点通过条件。
- 流程启用/停用。

#### 审核动作

- 提交。
- 通过。
- 退回修改。
- 驳回。
- 补充材料。
- 撤回。

### 5.10 申报数据管理

#### 功能说明

管理员需要高效查看和处理大量申报数据。

#### 列表能力

- 项目筛选。
- 状态筛选。
- 单位筛选。
- 申报人搜索。
- 审核节点筛选。
- 提交时间筛选。
- 批量操作。

#### 批量操作

- 批量导出申报表。
- 批量导出附件包。
- 批量生成汇总表。
- 批量退回。
- 批量归档。

### 5.11 导出与归档

#### 导出类型

- 单份申报 PDF。
- 批量 PDF 包。
- 附件压缩包。
- Excel 汇总表。
- 审核记录表。

#### 归档规则

- 项目归档后配置只读。
- 材料只读。
- 审核记录不可修改。
- 归档数据可导出。
- 系统管理员可解档。

### 5.12 操作日志与安全

#### 日志范围

- 创建项目。
- 修改配置。
- 发布配置。
- 审核材料。
- 导出数据。
- 修改权限。
- 归档项目。

#### 日志字段

| 字段 | 说明 |
| --- | --- |
| operator_id | 操作人 |
| action | 操作类型 |
| target_type | 操作对象类型 |
| target_id | 操作对象 ID |
| before_json | 修改前 |
| after_json | 修改后 |
| ip | 操作 IP |
| created_at | 操作时间 |

#### 安全能力

- 敏感导出记录。
- 导出水印。
- 操作频率限制。
- 只读归档。
- 管理员二次确认高危操作。

## 6. 前端交互设计

### 6.1 申报配置编辑器

建议整体布局：

```text
左侧：模块结构树
中间：打印布局画布
右侧：属性面板
```

#### 左侧结构树

- 模块。
- 子模块。
- 内容块。
- 支持拖拽排序。
- 支持复制块。
- 支持重命名。

#### 中间画布

- 展示最终打印布局。
- 支持点击选中单元格、字段、列、签章栏。
- 支持拖拽调整顺序。
- 支持占格调整。

#### 右侧属性面板

- 根据选中对象变化。
- 每行展示两个配置项。
- label 简短。
- 删除类操作使用图标按钮。
- 高级配置折叠展示。

### 6.2 配置发布流程

```text
编辑草稿 -> 保存 -> 校验 -> 预览 -> 发布 -> 生成版本记录
```

发布前必须校验：

- 配置结构合法。
- 打印布局合法。
- 引用字段存在。
- 审批流完整。

## 7. 后端接口设计

### 7.1 模板接口

```http
GET    /api/declaration-config/templates
POST   /api/declaration-config/templates
GET    /api/declaration-config/templates/{id}
PUT    /api/declaration-config/templates/{id}
DELETE /api/declaration-config/templates/{id}
POST   /api/declaration-config/templates/{id}/apply
```

### 7.2 配置版本接口

```http
GET  /api/projects/{project_id}/declaration-config/versions
POST /api/projects/{project_id}/declaration-config/versions
POST /api/projects/{project_id}/declaration-config/versions/{version_id}/publish
POST /api/projects/{project_id}/declaration-config/versions/{version_id}/clone
GET  /api/projects/{project_id}/declaration-config/diff?from=1&to=2
```

### 7.3 校验接口

```http
POST /api/projects/{project_id}/declaration-config/validate
```

返回示例：

```json
{
  "valid": false,
  "errors": [
    {
      "level": "error",
      "path": "modules[0].subModules[1].sections[2]",
      "message": "打印总列数小于字段占格总和"
    }
  ],
  "warnings": []
}
```

### 7.4 导出接口

```http
POST /api/projects/{project_id}/materials/export/pdf
POST /api/projects/{project_id}/materials/export/attachments
POST /api/projects/{project_id}/materials/export/summary
```

## 9. 实施计划

### 第一期：配置效率提升

- 内容块复制。
- 项目配置复制。
- 配置模板库。
- 配置导入导出。
- 基础配置校验。

### 第二期：打印布局增强

- A4 分页预览。
- PDF 预览。
- 行高、边框、对齐方式。
- 打印布局校验。
- 声明签章、左侧合并标题等固定布局完善。

### 第三期：版本与治理

- 配置版本对比。
- 配置影响分析。
- 发布审批。
- 回滚。

### 第四期：数据管理与归档

- 批量导出。
- 统计分析。
- 项目归档。
- 操作日志。
- 敏感导出水印。

## 10. 风险与注意事项

- 配置 JSON 已经复杂，后续需要稳定 schema 版本。
- 打印布局能力增强后，需要统一预览和实际 PDF 渲染逻辑。
- 字段 key 不能随意变更，否则会影响历史申报数据。
- 归档后必须只读，避免历史材料被配置变更影响。
- 批量导出涉及敏感信息，需要权限和日志。

## 11. 建议优先级

优先做：

1. 配置模板库。
2. 历史项目复制。
3. 配置校验。
4. A4/PDF 预览。
5. 批量导出。

原因：

- 这几项最直接降低管理员工作量。
- 能减少配置错误。
- 对当前申报配置编辑器改造收益最大。
