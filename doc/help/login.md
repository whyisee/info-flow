# 登录页

入口路径：`/login`

## 页面用途

登录页用于用户进入 InfoFlow 系统。用户输入用户名和密码后，系统校验账号状态与密码，登录成功后进入申报首页。

## 操作步骤

1. 打开系统登录页。
2. 在“用户名”输入框填写登录名。
3. 在“密码”输入框填写账号密码。
4. 点击“登录”按钮。
5. 登录成功后，系统跳转到 `/declaration/dashboard`。

## 补充说明

- 没有账号的用户可点击“去注册”进入注册页面。
- 如果提示“登录失败，请检查用户名和密码”，请确认账号、密码和账号启用状态。
- 登录后可见菜单由账号角色和权限决定。
