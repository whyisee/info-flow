# 权限目录

入口路径：`/system/permissions/catalog`

## 页面用途

权限目录用于查看系统内置权限点，是角色授权和菜单权限控制的基础。

## 操作说明

1. 进入“系统 / 用户与安全 / 权限目录”。
2. 查看系统按模块维护的权限点。
3. 在配置角色权限时，以权限目录中的权限点作为授权依据。

## 注意事项

- 截图采集时页面主体仅显示“权限目录”标题，详细权限内容可能仍在开发或受接口数据影响。
- 前端菜单可见性与权限点编码保持一致。
