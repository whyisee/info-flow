# 角色授权

入口路径：`/system/permissions/roles`

## 页面用途

角色授权用于维护角色与权限点之间的绑定关系。

## 操作说明

1. 进入“系统 / 用户与安全 / 角色授权”。
2. 查看系统角色列表。
3. 进入某个角色后，勾选或取消对应权限。
4. 保存后，该角色下用户的菜单和接口权限随之变化。

## 注意事项

- 截图采集时页面主体仅显示“角色授权”标题，详细授权表单可能仍在开发或受接口数据影响。
- 调整角色权限会影响所有绑定该角色的用户，应谨慎操作。
